# Ideias

## 1. Simples Publicador

Programa do usuario envia o Y de uma função e a página vai mostrando esta função


## 2. Simples Assinante

A página envia valores da odometria e o programa do usuario precisa calcula o X,Y,Theta para cada leitura e mostrar o gráfico que o robô fez

## 3. Controle do Robô

O programa do usuario precisa a cada segundo enviar as ordens dos motores (cmd_vel) para o robô.
